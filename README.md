🚀 How to Clone and Listen Offline
If you would like to download all the audio files at once to your local machine, mobile phone, or storage media for offline distribution, follow these instructions:

Using Git (Recommended for updates)
Bash
# Clone the repository
git clone [https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git](https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git)

# Navigate into the audio directory
cd YOUR-REPO-NAME/audio
Direct Download
Alternatively, you can download the entire repository as a compressed file by clicking on the green "Code" button at the top right of this page and selecting "Download ZIP".

🛠️ Contribution and Content Integrity
We are continuously seeking to expand the availability of recorded scripture portions. If you have audio recordings of other books of the Bible in Vasavi, corrections, or better quality formats, please get in touch or open a Pull Request.

Submission Guidelines:
Ensure files are encoded in standard compressed formats (.mp3 or .m4a).

Maintain clear naming conventions specifying the scripture book and chapter (e.g., john_01.mp3).

Accompany submissions with clear dialect verification (if applicable).
